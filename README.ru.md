# TG Media Save

[简体中文](README.md) | [English](README.en.md) | **Русский**

Репозиторий: [LazyFaiz/tg-media-save](https://github.com/LazyFaiz/tg-media-save). Название установленного расширения — **TG Media Save**; в названиях проекта и файлов выпуска используется `tg-media-save`.

Проект основан на [eiler2005/tg-media-saver](https://github.com/eiler2005/tg-media-saver) с сохранением указания автора и [лицензии MIT](LICENSE). Сохраняйте только доступный вашему аккаунту контент, на сохранение которого у вас есть право. Инструмент не отправляет сообщения и не собирает данные.

![Кнопка сохранения медиа в Telegram Web](docs/assets/hero-banner.png)

## Возможности

Добавляет кнопки скачивания фото, видео, GIF и голосовых сообщений в Telegram Web, включая клиенты `/k/` и `/z/`. Доступен как расширение Chrome / Edge MV3 и userscript для Tampermonkey / Violentmonkey; оба варианта собираются из одного исходного файла. Проект не связан с Telegram.

- Кнопки на медиа и плавающая кнопка слева внизу для последнего обнаруженного медиа.
- Имена и размеры файлов из корректных дескрипторов документов; для обычных Blob создаются имена по умолчанию.
- Определение исходного файла для WebK HLS / MediaSource, скачивание по частям и повтор временно неудачных запросов.
- Инструмент не входит в аккаунт, не публикует записи и не отправляет сообщения от вашего имени; не собирает данные и не имеет сторонних зависимостей во время работы.

## Текущая версия: 1.0.5

21 сентября 2026 года пользователь подтвердил успешное скачивание ранее проблемного видео Telegram WebK. Его проигрыватель MediaSource заменял исходный HLS-адрес адресом `blob:`; версия 1.0.5 запоминает источник до замены и скачивает соответствующий исходный файл.

Пройдено 49 автоматических тестов. Эта ручная проверка относится к одному видео и не подтверждает работу со всеми клиентами, видами медиа или окружениями userscript.

## Установка

1. [Скачайте ZIP с расширением](https://github.com/LazyFaiz/tg-media-save/raw/main/dist/tg-media-save-extension.zip) и распакуйте его либо используйте папку `extension/` из репозитория. Требуется Chrome / Chromium 111 или новее.
2. Откройте `chrome://extensions` в Chrome или `edge://extensions` в Edge и включите режим разработчика.
3. Отключите старую версию TG Media Saver и дублирующие скрипты с той же функцией.
4. Нажмите **Load unpacked** («Загрузить распакованное расширение») и выберите папку с `manifest.json`.
5. **Обновите страницу Telegram, затем заново откройте и воспроизведите видео** и нажмите кнопку скачивания.

Для установки userscript используйте [tg-media-save.user.js](tg-media-save.user.js). Выберите расширение или userscript, не устанавливайте оба одновременно. В Chrome MV3 включите **Allow user scripts** для Tampermonkey в настройках расширения. В скрипте не заданы явные `@updateURL` / `@downloadURL`: при обновлении переустановите файл из этого репозитория, не полагаясь на автоматическое обновление.

## Использование

1. Откройте Telegram Web и запустите видео или аудио либо откройте фото, чтобы страница загрузила медиа.
2. Нажмите кнопку скачивания на медиа или плавающую кнопку слева внизу, чтобы сохранить последнее обнаруженное медиа.
3. Если браузер откроет окно сохранения, выберите место и дождитесь завершения скачивания.

Соблюдайте условия использования Telegram и авторские права владельцев контента.

![Кнопка скачивания на видео в Telegram Web](docs/assets/demo-button.png)

## Обновление

1. Получите последнюю версию кода или архива и обновите папку, из которой браузер загружает расширение.
2. Перезагрузите **TG Media Save** в менеджере расширений и проверьте версию **1.0.5**.
3. **Обновите страницу Telegram и заново откройте видео.** Одна перезагрузка расширения не позволит захватить источники медиа, уже созданные на старой странице.
4. Воспроизведите медиа и нажмите кнопку скачивания.

## Как происходит скачивание и какие есть ограничения

- WebK HLS / MediaSource: исходный адрес связывается с конкретным медиаэлементом; корректный HLS-адрес документа того же сайта преобразуется в запрос потока. Видео не определяется по последнему сетевому запросу.
- Обычные Blob: ссылки на файлы сохраняются при создании, поэтому файл можно скачать и после отзыва его URL. Кэш ограничен 32 записями и 512 МиБ в сумме; каждая запись хранится пять минут. При превышении лимитов старые записи удаляются, а слишком большие файлы не сохраняются в кэше.
- Скачивание по частям: каждый запрос — не более 1 МиБ; при временных сетевых сбоях выполняется до трёх попыток. Проверяются диапазон, число байтов и общий размер.
- При наличии File System Access API части записываются на диск, иначе файл собирается в памяти. Обычные Blob сохраняются через механизм загрузки браузера.
- MediaSource не является обычным файлом. Если исходный адрес не был захвачен, скачать его `blob:` напрямую нельзя. Изменения в проигрывателе Telegram могут повлиять на совместимость.

## Диагностика

Сначала проверьте, что страница обновлена, а видео открыто заново. Если скачивание всё равно не работает, выполните в консоли разработчика **на странице Telegram**:

```js
JSON.stringify(tgSaver.diagnose())
```

Результат содержит версию, состояние захвата, размер кэша и категории источников медиа, но не полные URL медиа и не текст сообщений. `tgSaver.status()` и `tgSaver.debug(true)` предназначены для разработчиков и могут раскрывать сведения об источнике; для отчёта об ошибке используйте `diagnose()`.

| Поле | Значение |
|---|---|
| `sourceCaptureInstalled` | Установлен ли перехват исходного адреса |
| `blobCaptureInstalled` | Установлен ли перехват типов Blob / MediaSource |
| `sourceType: "stream"` | Определён адрес файла для скачивания |
| `capturedType: "MediaSource"` | Обнаружен объект проигрывателя, но исходный адрес файла пока не определён |
| `capturedType: "not-retained"` | URL отсутствует в кэше; для потока это нормально |
| `readyState: 0` | Медиаэлемент ещё не загружен; на странице могут быть неактивные элементы |

При сообщении об ошибке приложите результат диагностики, текст ошибки и укажите, воспроизводится ли видео. Само по себе `Failed to fetch` не позволяет отличить сетевую ошибку от отозванного Blob или MediaSource. Если видео тоже не воспроизводится, восстановите сеть и обновите Telegram; не включайте для Service Worker параметр **Bypass for network**. Подробнее: [устранение неполадок](docs/TROUBLESHOOTING.md).

## Разработка

Нужны Node.js 18+ и Python 3 (`python` в PATH); во время работы расширению не требуются сторонние библиотеки.

```sh
npm run build
npm test
```

Логику меняйте в `src/content.js`; сборка создаёт скрипт расширения, userscript и ZIP. Версия задаётся в `extension/manifest.json`. `scripts/build.sh` — совместимый способ вызвать `python3 scripts/build.py`.

сохранение медиа из Telegram Web

  1. Откройте Telegram Web и воспроизведите видео/аудио (или откройте фото).
  2. Нажмите ⬇ на самом медиа — или плавающую кнопку ⬇ слева внизу.
  3. Файл сохранится с настоящим именем; прогресс виден в процентах.

Кнопка появляется только когда страница реально загрузила медиа. Если видео не играет — см. раздел Troubleshooting в README.
